# Kasir Warkop Gemilang Jaya

Aplikasi owner/kasir Warkop Gemilang Jaya yang bisa diinstal di HP (PWA).
Aplikasi ini membuka halaman kasir dari Google Apps Script dalam layar penuh.

- `index.html`: halaman aplikasi (berisi alamat Apps Script)
- `manifest.json`: nama & ikon aplikasi
- `sw.js`: agar bisa diinstal
- `icon.png`: logo
